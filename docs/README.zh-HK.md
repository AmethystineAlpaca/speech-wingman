# Speech Wingman

**你自然咁講，佢幫你留意想改善嘅表達習慣。**

Speech Wingman 係一個喺 Mac 本機運行嘅語音提醒助手。用日常語言寫低規則，撳一下懸浮咪高峰就可以開始講；符合規則時，佢會引用原話，再畀你一個簡短提醒。適合開會、面試同演講練習。

**Multilingual（英文、中文、日文、韓文，甚至廣東話）· 同一段對話交替講 · 完全離線**

[English](../README.md) · [简体中文](README.zh-CN.md) · [日本語](README.ja.md) · [한국어](README.ko.md)

*開源開發預覽版 · Apple Silicon · macOS 14 或以上 · 暫時需要喺本機自行建置。*

## 五種語言，同一段對話

今次嘅規則係：「無論用邊種語言，講到香蕉就提醒。」一條連續音訊順序講英文、普通話、日文、韓文同廣東話，再用自然停頓交替講一次。全程冇轉過識別語言，提醒一直用所選嘅英文。

*示範用 macOS 合成語音讀出虛構句子，以正常速度輸入正式嘅識別、判斷、會話控制同介面程式碼，只係用音訊回放代替咪高峰。轉錄同提醒都由模型實際產生，唔係預先填好嘅答案。影片有原本嘅合成語音，GIF 冇聲。呢個係開發示範，唔代表真人咪高峰識別準確率。*

自然停頓有幫助。如果喺同一個未停頓嘅片段入面轉語言太快，仍然可能漏字或者認錯。[只隔 250 毫秒嘅壓力測試](assets/multilingual-rapid-stress.json)保留咗呢種失敗，唔會將多語言支援講成任何混說都零錯誤。

## 功能

- **規則由你定：** 每行一條，例外條件寫喺同一行；符合任何一條就提醒。
- **多語言自動識別：** 英文、中文、日文、韓文同廣東話，同一段會話可以交替講，唔使人手轉識別模式。
- **介面同提醒語言：** 預設英文，可揀英文、簡體中文、日文或韓文，並保留設定。廣東話屬於語音輸入支援，暫時冇獨立廣東話介面。
- **私隱留喺本機：** 識別同判斷都喺 Mac 做；應用及輔助程序冇網絡權限，唔會自動儲存錄音或轉錄。
- **自己控制：** 懸浮按鈕、即時轉錄、暫停／繼續、靜音一小時、停止並清空，以及主動匯出會話。

自訂規則、轉錄同引用保留原文；新提醒會用你揀嘅語言產生。規則合共最多 4000 字。

## 建置同使用

需要 Apple Silicon Mac、macOS 14 或以上、Swift 6 或以上、Apple Command Line Tools 或 Xcode、Git，同 ARM64 Python 3.9 或以上。建議有 16GB 記憶體同 10GB 可用空間。第一次下載依賴同模型要上網，建置好之後就可以離線用。

跟住[建置指南](guide.md#getting-started)完成安裝，再喺設定寫規則、儲存並開始聆聽。介面語言喺 **Settings → Interface and alert language** 選擇。應用使用本機簽署，未經 Developer ID 公證。

## 驗證同限制

20 組核心測試通過。之前獨立做嘅模型回歸測試係 63/73，失敗案例亦有保留，見[驗證記錄](validation.md)同[長時間測試](../Samples/UltimateTestCase/README.md)。

專有名詞、口音、多人同時講嘢、快速轉語言、長篇發言，都可能影響準確度或延遲。應用唔會分辨邊個講嘢。
