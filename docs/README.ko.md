# Speech Wingman

**자연스럽게 말하세요. 직접 정한 규칙에 해당할 때 짧게 알려 드립니다.**

Mac에서 실행되는 음성 알림 도우미입니다. 일상 언어로 규칙을 적고 플로팅 마이크를 눌러 말하면, 규칙에 해당하는 발언을 인용하여 알려 줍니다. 회의, 면접, 발표 연습에 사용할 수 있습니다.

**Multilingual (영어, 중국어, 일본어, 한국어, 광둥어까지) · 대화 중 언어 전환 · 완전한 오프라인 실행**

## 다섯 언어, 하나의 세션

이번 규칙은 “어떤 언어로든 바나나를 언급하면 알림”입니다. 하나의 연속 음성에서 영어, 중국어, 일본어, 한국어, 광둥어를 차례로 말한 뒤, 자연스럽게 쉬어 가며 다시 언어를 바꿉니다. 인식 언어 설정을 바꾸지 않았으며 알림은 선택한 영어로 유지됩니다.

*가상의 문장을 macOS 음성 합성으로 만들고 정상 속도로 실제 인식, 판단, 세션 제어 및 화면 코드에 입력했습니다. 마이크 입력만 음성 재생으로 대체했습니다. 전사와 알림은 미리 작성한 결과가 아닌 실제 모델 출력입니다. 동영상에는 원본 합성 음성이 포함되며 GIF에는 소리가 없습니다. 실제 화자의 마이크 인식 정확도 평가를 뜻하지는 않습니다.*

자연스러운 쉼은 인식에 도움이 됩니다. 한 발화 안에서 언어를 매우 빠르게 바꾸면 단어가 누락되거나 잘못 인식될 수 있습니다. [250밀리초 간격 스트레스 테스트](assets/multilingual-rapid-stress.json)에는 이러한 실패도 그대로 남겨 두었습니다.

## 주요 기능

- **나만의 규칙:** 한 줄에 조건 하나와 예외를 작성합니다. 어느 규칙이든 해당하면 알립니다.
- **다국어 자동 인식:** 영어, 중국어, 일본어, 한국어, 광둥어를 지원합니다. 대화 중 언어를 바꿔도 인식 설정을 변경할 필요가 없습니다.
- **화면 및 알림 언어:** 기본값은 영어입니다. 영어, 중국어, 일본어, 한국어 중에서 선택할 수 있으며 설정이 저장됩니다. 광둥어는 음성 입력을 지원하며 별도의 화면 언어는 아닙니다.
- **개인정보 보호:** 인식과 판단은 Mac에서 실행됩니다. 앱과 보조 프로세스에는 네트워크 권한이 없습니다. 음성과 전사는 자동 저장되지 않습니다.
- **직접 제어:** 플로팅 버튼, 실시간 전사, 일시 정지와 재개, 1시간 알림 끄기, 중지 및 지우기, 세션 내보내기.

직접 작성한 규칙과 전사 및 인용은 원문을 유지합니다. 새 알림은 선택한 언어로 생성됩니다. 규칙은 모두 합쳐 4000자까지 입력할 수 있습니다.

## 빌드하고 사용하기

Apple Silicon Mac, macOS 14 이상, Swift 6 이상, Apple Command Line Tools 또는 Xcode, Git, ARM64 Python 3.9 이상이 필요합니다. 메모리 16GB와 여유 공간 10GB를 권장합니다. 최초 의존성과 모델 다운로드에는 인터넷이 필요하지만, 빌드한 앱은 오프라인으로 실행됩니다.

[빌드 안내](guide.md#getting-started)에 따라 앱을 만든 뒤 설정에서 규칙을 저장하고 듣기를 시작하세요. 한국어 화면은 **Settings → Interface and alert language → 한국어**에서 선택합니다. 앱은 로컬 서명 상태이며 Developer ID 공증 배포판은 아닙니다.

## 검증과 한계

핵심 테스트 20개 그룹을 통과했습니다. 별도로 진행한 이전 모델 회귀 테스트는 73개 중 63개를 통과했으며 실패 사례도 보존되어 있습니다. [검증 기록](validation.md)과 [장시간 테스트](../Samples/UltimateTestCase/README.md)를 확인하세요.

인식과 규칙 판단은 완벽하지 않습니다. 고유명사, 억양, 겹치는 음성, 빠른 언어 전환, 긴 발언은 오류나 지연을 일으킬 수 있습니다. 화자를 구분하지 않습니다.

앱 소스 코드는 MIT 라이선스입니다. 모델과 의존성에는 각각의 라이선스가 적용됩니다. [타사 라이선스](../THIRD_PARTY_NOTICES.md)를 확인하세요.
